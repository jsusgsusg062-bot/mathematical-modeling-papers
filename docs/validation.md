## 独立试用A：已有搜索结果的优化题

输入：生鲜配送，容量与时间窗约束；已有四篇摘要线索，分别涉及混合整数规划、遗传算法、损耗成本和销量预测。用户问下一步搜索哪些关键词。

观察到的行为：

- 没有强制开启新检索，建议先核对已有A、B论文。
- 把损耗成本论文列为取决于题目要求的备选，暂缓销量预测论文。
- 区分混合整数规划的模型形式与遗传算法的求解作用。
- 提醒核对软/硬时间窗，未凭摘要推定全部适用。
- 仅安排本轮回传题名与完整摘要，没有操作知网或给完整长教程。

结论：本场景下，技能能够跳过多余检索、处理非预测题、依据已见证据初筛。

## 独立试用B：真实论文拆解

输入：用户提供的吴振阳、邢杰《基于多元回归和GM的新能源汽车保有量预测》，《智能计算机与应用》2024年14卷10期214—217页，DOI:10.20169/j.issn.2095-2163.241031。未提供赛题。评估实例仅获得技能与原PDF，没有获得先前聊天记录或主代理的阅读结论。

核对点及观察：

| 核对点 | 观察到的输出 | 原文位置 |
|---|---|---|
| 方法分工 | Pearson筛变量；回归估计输入到目标关系；GM预测未来输入；再代入回归 | 第215—216页 |
| 最终建模窗口 | 回归2013—2022；输入GM使用2015—2022 | 第215—216页，第2节 |
| 回测窗口 | 回归2013—2019；输入GM使用2015—2019；预测2020—2022 | 第216页，第3.1节 |
| 效果归属 | 把8.6%与27.5%记为作者报告的平均误差，保留口径疑问 | 第216—217页 |
| 拟合与未来预测 | 没有把R²当未来预测准确率，没把2023—2025预测当实际值 | 第215—217页 |
| 公式与单位 | 解释回归变量、单位及GM与回归的连接 | 第215页式2、第216页表2 |
| 原文/补充区分 | 标明标准GM(1,1)讲解是背景，未冒充作者完整实现 | 全文披露范围 |
| 未给赛题 | 只给迁移思想，不虚构本题数据或最终选模结论 | 用户输入范围 |

独立实例指出：文中2022年实际值1310、表4预测值1018.23与28.65%的误差，按实际值作分母不能一致；按预测值作分母则吻合。主代理另行核对了相关原图。这只证明表4的口径值得澄清，不等于完整复算了作者报告的三年平均误差。

它还区分了“未来输入预测更准”与“输入误差可能抵消回归偏差”，没有从最终目标误差倒推出所有输入预测准确。

## 验证范围与后续

本轮未完整复现论文实验：原始年度数据与GM实现细节不足。已验证的是阅读流程和证据处理，不是论文结果的科学正确性。

检索测试是模拟用户反馈，没有登录知网；没有验证所有知网版本或专业检索语法。尚未独立试用多篇异质论文比较、扫描PDF识别、评价题及机理题。后续按真实使用中出现的问题补充，不以文件校验通过声称这些场景已测试。

发布前将一个带具体数值的指标示例改为a%、b%的通用表述，减少对单篇案例的依赖；流程未改变。
