# 数学建模：文献检索与论文拆解 Skills

两个独立、可衔接的中文技能：先围绕赛题检索并筛选论文，再读懂论文的研究内容、模型、贡献与改动，通过阅读逐步形成建模认识。检索开始前不要求先确定完整建模路线。

| Skill | 负责什么 | 默认工作方式 |
|---|---|---|
| [数模文献检索教练](skills/modeling-literature-search/SKILL.md) | 拆题、关键词、递进检索、题名摘要初筛 | 你操作知网；助手每轮给当前操作，依据反馈决定下一步 |
| [数模论文拆解](skills/modeling-paper-dissection/SKILL.md) | 研究内容、模型分工、贡献与改动、相关证据、可迁移部分 | 按当前要求与会话约定选择速读或精读；均无时默认速读；支持单篇和多篇 |

当前检索技能采用“你操作知网，助手指导并筛选”的方式，不提供自动联网代搜、登录、抓取或下载。它给出的查询建议不等于已经检索到的论文。

## 使用示例

检索：

```text
请用 $modeling-literature-search 帮我拆这道数学建模题。
我自己操作知网，你每次只给当前一轮的搜索方案。
[粘贴题目；如有已有结果，也一起提供]
```

已有结果：

```text
请用 $modeling-literature-search 筛选下面这些题名和摘要，
判断哪些值得下载；已有信息足够时直接进入阅读，不必重新搜。
```

论文速读：

```text
请用 $modeling-paper-dissection 速读附件论文。
讲清楚它研究什么、整体怎么做、模型和算法分别负责什么，
主要贡献及证据是什么，以及可以借鉴什么；有方法改进时说明改了哪里。
[有赛题时可以一并提供；没有也能读论文]
```

论文精读：

```text
请用 $modeling-paper-dissection 精读这篇论文的方法与贡献部分。
解释关键变量、公式、约束和求解步骤，核对贡献依据；有方法改进时核对基线与实验，
并列出准备实现时仍然缺少的信息。
```

多篇比较：

```text
请用 $modeling-paper-dissection 先分别拆解这几篇论文，
再比较方法思路、各自贡献与改动、数据要求、验证证据和对本题的适配性。
不同数据集上的误差不要直接排名。
```

## 两者如何衔接

检索端交给阅读端：子问题、已知数据与约束、候选论文及已有链接/DOI、选择理由、已见材料层级与全文可读性、希望阅读回答的问题。

阅读端优先回应交接问题，深度按“当前明确要求→当前会话已约定的深度→默认速读”选择。已约定“后面都详细拆”时，下一篇只说“继续”仍按精读处理；单篇临时要求不改变后续约定。可以直接要求精读，不需要逐节确认。只有摘要时也可有限拆解，不把摘要概括当成全文核对。

阅读端交回检索端：未解决的问题、原文位置、为什么影响建模选择、已知关键词及需要的证据。

两个技能均可单独使用，另一个未安装时仍可输出交接信息。

## 设计边界

- 不自动操作知网，不需要浏览器自动化、API密钥或Zotero。
- 不强制每个题都经过全部检索轮次；找到有用论文就读。
- 覆盖预测、优化、评价、分类和机理/仿真；不套固定模型清单。
- 论文拆解保留原文依据，区分作者报告与助手分析。
- 贡献分析涵盖方法改进、问题适配及比较/验证所得；有方法改进时回答“原方法→具体改动→动机→证据”，不硬凑创新点。
- 无本题实验结果时只给候选路线，不编造模型精度排名。
- 默认在对话中交付，不自动生成Excel、代码或长报告文件。
