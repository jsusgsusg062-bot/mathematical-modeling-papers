# 知网操作指导参考

依据：用户于 2026-09-07 提供的首页、CNKI AI 与高级检索截图。这里是可见界面的操作参考，不是所有版本的永久规范。只指导用户操作，不调用浏览器、登录、爬虫或下载。

## 高级检索

截图可见高级检索、专业检索、作者发文检索、句子检索标签；多行字段选择、行间 AND 下拉、精确匹配控件、增删行、时间范围；OA出版、网络首发、增强出版、基金文献与词扩展选项；下方有期刊、学位论文等文献类型。

默认第二、三行显示作者与文献来源。搜索多个主题时需让用户修改字段或删除多余行，不能把关键词输入作者栏。初轮通常不限制作者、基金、OA、核心来源和过短年份；仅在任务需要时加条件。

选择字段时：主题用于探索；题名与关键词用于聚焦；摘要用于任务/约束组合；全文用于具体表述但噪音较多。若当前字段列表没有某项，改用已有项。不要把主题与篇关摘当作永久等价字段。

## 语法分层

1. 自然语言逻辑：例如（冷链配送 或 生鲜配送）并且 时间窗。这只解释意图。
2. 高级检索行内表达式：截图右侧帮助明确显示 `*` 为与、`+` 为或、`-` 为非；使用英文半角括号明确优先级。确认同类界面后，可在一行填 `(冷链配送 + 生鲜配送)`，下一行主题填 `时间窗`，行间选择 AND。
3. 专业检索：字段代码与匹配符语法单独核对当前“专业检索使用方法”。此截图未展示专业检索帮助，不从 GitHub 示例推定 `SU%=`、年份比较或邻近位置符全部可用。不熟悉或无法核实时先用高级检索多行方案。

本截图帮助提示单框内容不超过120字符；这只是该入口显示的限制。检索词本身含空格或特殊字符时，按帮助使用英文半角引号包裹。区分运算符和检索词里的字面符号，例如 `GM(1,1)` 可能需要引号。

## CNKI AI：只输出当前一轮提示词

截图可见“知网文献”下拉、“联网搜索”和“深度思考”，以及文献综述、文献计量、智能研读等入口。只确认控件存在，不声称下拉选项内容、付费权限、默认范围或这些模式的准确率。用于知网文献探索时先让用户确认当前来源；外网信息与知网文献证据分别标记。

第一轮示例（替换方括号，只给与当前目标相关的部分）：

> 我在研究[子问题]。请基于所列文献，整理学术术语、主要建模路线及少量代表文献题名。区分真正同义词和近邻任务，区分数学模型、求解算法和解释方法。对每条路线说明文献解决的具体任务；无法确认的信息写“未确认”。此轮先不决定最佳模型。

第二轮仅在第一轮有具体缺口时使用：

> 请针对[候选路线/文献]补充实际输入输出、数据时间跨度与频率、样本规模、方法分工、验证方式及出处。把原文信息与推断分开；不要把某篇的数据量写成模型最低样本要求。前后不一致的描述请标出待原文核对。

不要连续让 AI 泛化总结代替读原文。用户带回的生成结果属于二手概括；引用存在不代表概括正确，但用户已确认存在的文献无需再做存在性检查。
