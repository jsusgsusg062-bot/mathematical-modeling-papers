# 论文提取与讲解模板

## 数据与流程

记录实际使用的数据，而非泛泛“需要大样本”：来源、对象、时间跨度与频率、样本单位、数量、缺失/异常处理、输入输出单位、训练与验证的不同窗口。一个方法链中不同环节可能使用不同年份，不合并成单一训练范围。

对每个核心环节填写：

| 环节/方法 | 输入 | 输出 | 负责什么 | 如何拟合或求解 | 原文依据 |
|---|---|---|---|---|---|

解释“为什么这样连接”。例如未来自变量先预测再代入回归，与先拟合趋势再预测残差、多个预测加权融合是三种不同结构；只有证据支持才归类。

## 贡献与改动

先说明论文提供了什么模型、问题适配或研究认识；一篇论文可以兼有多类贡献。存在方法改进时，再记录“原方法或基线→具体改动及所在环节→动机→证据”，并保留原文位置和可支持的结论。摘要或正文未给基线时写明范围，不能替作者虚构一个传统方法作对照。

按实际工作选择相关项目，不要求每篇都有方法创新或下列所有内容：

| 工作类型 | 需要解释的内容 |
|---|---|
| 模型结构 | 变量、目标函数、约束、关系或模块连接改在哪里 |
| 求解算法 | 搜索、更新、初始化、终止或计算流程怎样改变 |
| 参数或数据处理 | 调参、特征构造、清洗或采样在方法链中起什么作用 |
| 已有方法组合 | 各已有方法如何连接，组合要解决什么问题；组合本身不证明优于单独使用 |
| 新场景应用 | 哪些原有假设需要适配、应用价值是什么；使用成熟方法不自动构成算法创新 |
| 比较或验证 | 比较了哪些方法或条件、检验了什么主张、获得了什么认识，以及证据适用范围 |

“求解一个优化模型”和“改进一个模型或算法”分开说明。主要应用标准方法时，解释其用途及对问题、数据和约束的适配；主要比较或验证时，解释结论与条件。没有方法创新不意味着缺少可借鉴内容。用户问改进而所给材料没有说明时，如实说明范围，不硬凑创新点。

贡献与效果依照 [效果证据指南](evidence-and-comparison.md) 中的原则核对。整体方案优于基准，不自动证明某一个新增模块单独有效；缺少消融或针对性证据时保留归因范围。理论证明、可行性、稳定性、时间或误差均可构成相关证据，按论文任务选择，不统一要求精度提升。

## 按任务展开

| 论文任务 | 关键拆解内容 | 效果证据重点 |
|---|---|---|
| 预测/回归 | 目标、预测时点与步长、历史/外生变量、信息可用性、拟合与预测流程 | 样本外误差、时间划分、基准与不确定性 |
| 分类/识别 | 标签定义、类别分布、输入、概率与阈值 | 混淆矩阵、召回/精确率、F1、AUC等及具体口径 |
| 优化/调度 | 决策变量与取值域、目标、约束、参数、求解算法与终止条件 | 可行性、目标值、基准、最优界/间隙、运行时间 |
| 综合评价 | 指标方向、尺度处理、赋权来源、聚合与排序机制 | 权重敏感性、排序稳定性、外部验证 |
| 机理/仿真 | 状态变量、动力学方程、初边值、参数标定、离散与数值求解 | 标定/验证分离、实测对照、数值稳定性与适用边界 |
| 理论 | 问题定义、假设、定理、关键证明、适用范围 | 证明条件、界、是否存在未覆盖情况 |
| 综述 | 研究范围、分类依据、方法分歧与来源 | 覆盖边界与证据脉络；不虚构作者自建预测实验 |

## 关键公式讲解

精读时保留决定模型含义的公式，并给符号表、单位、输入输出与约束意义。区分估计的参数、输入数据和待求决策变量。解释公式如何变成算法步骤，别只抄符号。速读通常先用输入、输出和作用说明方法；公式是理解用户问题的关键时再展开。

论文没有给标准算法细节时，可以解释通用背景，但标明“背景解释，并非本文完整实现”。不虚构超参数、软件版本、收敛判据或缺失方程。只有真实运行才称“复现”或“重算”。

## 可复现性与问题表达

采用“观察→依据→影响→可做的检查”。例如：表格中若干自变量高度相关，提示系数可能不稳定，可检查共线性；不能由此声称作者计算了VIF，也不能直接下结论模型必然无效。

未报告VIF、消融、代码或运行时间，只表示该项证据缺失；根据任务判断影响，不要求所有论文补齐同一套实验。预测效果好不自动证明因果机制；SHAP解释的是模型输出，不独立建立因果关系。
