# 效果证据与公平比较

## 把“效果好”还原为实验

每个关键效果记录：谁与谁比较 / 同一任务吗 / 数据范围与规模 / 验证方式 / 指标定义与单位 / 原文数值 / 证据位置 / 可以支持的最窄结论。

- 训练集拟合 R² 高，不是未来预测能力或统计显著性的充分证据。
- 未来年份的预测数值不是已观察到的实际结果。
- 作者称“平均误差”而未给明确定义时保留该名称，不擅自改称 MAPE。零值/近零目标下的百分比误差可能失真，不能默认任何指标适用所有数据。
- 误差由a%降至b%时，差值以百分点表示；若讨论相对下降，需给出计算口径并标为助手重算。不要把误差下降写成同幅度的准确率提高。
- 表格、正文与图像不一致时并列记录位置与冲突，保留“不确定”，不挑一个数悄悄修正。
- 计算数值核对只在有助于判断且数据充分时做；缺真实值或指标公式时不假装复算过。

## 预测研究重点

对时序预测检查训练、验证、最终测试是否按时间先后；随机分割可能让未来信息进入过去。检验预处理、特征选择和调参是否仅使用相应训练部分。论文未说明时记“无法确认”，不要直接认定泄漏。

区分发出预测时已知的历史变量与未来才知道的变量。未来外生输入是另行预测、情景设定还是使用真实值？使用未来真实变量的回测是附加条件下的评估，不能与实际可部署预测无说明地并列。

模型选择用验证数据或适当的时间滚动验证；最终测试不反复用于调参。滚动验证的步长应贴合实际预测跨度。简单基准（如上一期/同季节值）视任务选择，不硬指定模型清单。用全量数据筛特征再回测是需核查的风险，不因一句“分了训练测试”就忽略。

Logistic增长曲线与Logistic分类回归不是同一个模型；按方程和输出区分。SARIMA属于统计时间序列模型，不是物理模型。RF、XGBoost需区分回归与分类版本。深度学习是机器学习子类，可为数据需求比较单列，但不判这种上位归类为错误。

## 优化与评价研究重点

启发式算法得到的最好可行解不等于已证明全局最优。记录约束是否满足、目标方向、基准和算力预算；声称最优时找证明、最优界或求解器证据。求解快与目标好是不同维度。非预测任务不强制 MAE、R² 或训练测试集。

评价模型中“熵权更客观”等表述是方法性质或作者主张，不是结果正确性的独立证据；看指标含义、赋权假设、敏感性和外部效度。不要用主观权重生成小数点精确的模型总分再宣称显著优越。

## 多篇比较

先按目标变量、预测跨度/问题规模、数据、约束和验证协议分组。只有可比条件才讨论数值高低；不可比时明确“不能直接排名”，比较所解决的难点、所需条件与证据强弱。

分开论文内效果、论文间可比性、对用户赛题的适配性。某篇报告某模型更好，并不决定用户数据上的胜者。样本数量是该实验的条件，不是模型普适最低门槛。
